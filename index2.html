À propos de MossAir
MossAir est né de la passion d'Arnaud Barotteaux pour l'innovation écologique. Formé chez Simplon, passionné de science-fiction et convaincu que la technologie doit servir la planète.
Notre philosophie : allier design minimaliste et filtration naturelle pour créer des purificateurs d'air qui fonctionnent avec la nature, pas contre elle.
Chaque produit MossAir utilise de la mousse végétale cultivée de manière responsable pour purifier l'air de votre intérieur.

Légende & Conventions
Guide de lecture des wireframes
Palette de couleurs
#2d4a2b — Navbar/Primary
#4a7c59 — Boutons/Accent
#6b8e7a — Hover/Secondary
#1a1a1a — Footer
#f9fdf9 — Background
Breakpoints responsive
Desktop : ≥992px — Nav horizontale, grilles multi-colonnes, sidebar
Tablette : 768px–991px — Nav horizontale compacte, 2 colonnes
Mobile : ≤767px — Menu hamburger, 1 colonne, bottom tabs (admin)
Composants récurrents
Navbar : Logo + liens + panier + auth (sticky top)
Footer : 4 colonnes (Environ, Boutique, Ressources, Support) + réseaux
Bandeau RGPD : Fixed bottom, 3 boutons, panneau personnalisation
Admin modal : Ctrl+A ou 3 clics logo → mot de passe admin
Technologies
Framework : Symfony 7 (PHP 8) + Twig
CSS : Bootstrap 5.3 + CSS custom (1380 lignes)
Base de données : MySQL (Doctrine ORM)
Sécurité : bcrypt, CSRF tokens, protection XSS

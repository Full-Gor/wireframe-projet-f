JavaScript et Interactivité

Menu Hamburger (IIFE)

Le menu hamburger utilise une IIFE (Immediately Invoked Function Expression) pour éviter les conflits de scope global. Il gère le toggle du menu, l'accessibilité via aria-expanded, et la fermeture automatique au clic sur un lien.

(function() {
    function initBurger() {
        const hamburger = document.getElementById('hamburger');
        const navMenu = document.getElementById('navMenu');
        if (!hamburger || !navMenu) return;

        hamburger.addEventListener('click', function(e) {
            e.preventDefault();
            hamburger.classList.toggle('active');
            navMenu.classList.toggle('active');
            hamburger.setAttribute('aria-expanded',
                navMenu.classList.contains('active'));
        });

        // Fermeture auto au clic sur un lien
        navMenu.querySelectorAll('a').forEach(link => {
            link.addEventListener('click', () => {
                hamburger.classList.remove('active');
                navMenu.classList.remove('active');
            });
        });
    }

    if (document.readyState === 'loading') {
        document.addEventListener('DOMContentLoaded', initBurger);
    } else {
        initBurger();
    }
})();

Accès Admin Secret

Deux méthodes d'accès cachées au dashboard administrateur : Ctrl+A (redirige vers /admin) et triple-clic sur le logo (ouvre un modal Bootstrap de confirmation).

document.addEventListener('DOMContentLoaded', function() {
    let clickCount = 0;
    let clickTimer = null;

    // Accès via Ctrl+A
    document.addEventListener('keydown', function(e) {
        if (e.ctrlKey && e.key === 'a') {
            e.preventDefault();
            window.location.href = '/admin';
        }
    });

    // Accès via triple-clic sur le logo
    const siteLogo = document.getElementById('siteLogo');
    if (siteLogo) {
        siteLogo.addEventListener('click', function(e) {
            e.preventDefault();
            clickCount++;

            if (clickTimer) clearTimeout(clickTimer);

            if (clickCount >= 3) {
                const modal = document.getElementById('adminModal');
                if (modal) {
                    new bootstrap.Modal(modal).show();
                }
                clickCount = 0;
                return;
            }

            clickTimer = setTimeout(() => {
                window.location.href = siteLogo.href;
                clickCount = 0;
            }, 600);
        });
    }
});

Timer de 600ms pour distinguer un simple clic (navigation normale) d'un triple-clic (accès admin). Le modal Bootstrap demande confirmation avant de rediriger vers le dashboard.

L'entité Produit représente un produit en base de données avec Doctrine ORM.

Code de l'Entity Produit

<?php

namespace App\Entity;

use App\Repository\ProduitRepository;
use Doctrine\ORM\Mapping as ORM;

#[ORM\Entity(repositoryClass: ProduitRepository::class)]
class Produit
{
    // Identifiant unique auto-incrémenté
    #[ORM\Id]
    #[ORM\GeneratedValue]
    #[ORM\Column]
    private ?int $id = null;

    // Nom du produit (obligatoire, max 255 caractères)
    #[ORM\Column(length: 255)]
    private ?string $nom = null;

    // Description détaillée (texte long, optionnel)
    #[ORM\Column(type: 'text', nullable: true)]
    private ?string $description = null;

    // Prix du produit (nombre décimal)
    #[ORM\Column]
    private ?float $prix = null;

    // Image et statut
    #[ORM\Column(length: 255, nullable: true)]
    private ?string $image = null;

    #[ORM\Column]
    private ?bool $actif = true;

    // === CHAMP STOCK ===
    // Quantité disponible en stock (INT, défaut 0)
    #[ORM\Column]
    private ?int $stock = 0;

    // Dates de création et modification
    #[ORM\Column]
    private ?\DateTimeImmutable $createdAt = null;
    #[ORM\Column]
    private ?\DateTimeImmutable $updatedAt = null;

Méthodes de Gestion du Stock

    // === MÉTHODES DE GESTION DU STOCK ===

    /**
     * Récupérer le stock disponible
     */
    public function getStock(): ?int
    {
        return $this->stock;
    }

    /**
     * Définir le stock disponible
     * Exemple : setStock(100) pour mettre 100 produits en stock
     */
    public function setStock(int $stock): static
    {
        $this->stock = $stock;
        return $this;
    }

    /**
     * Vérifier s'il reste du stock
     * Retourne true si stock > 0, false sinon
     */
    public function hasStock(): bool
    {
        return $this->stock > 0;
    }

    /**
     * Décrémenter le stock (enlever une quantité)
     * La fonction max(0, ...) empêche le stock de devenir négatif
     */
    public function decrementStock(int $quantity): static
    {
        $this->stock = max(0, $this->stock - $quantity);
        return $this;
    }
}

Points clés

  • Le champ stock est de type INT avec une valeur par défaut à 0
  • La méthode hasStock() vérifie rapidement si le produit est disponible
  • La méthode decrementStock() diminue le stock de façon sécurisée (jamais négatif)

/**
 * Migration pour ajouter la colonne 'stock' à la table produit
 * - up() = Ajoute la colonne stock
 * - down() = Supprime la colonne stock (annulation)
 */
final class Version20251203150000 extends AbstractMigration
{
    public function getDescription(): string
    {
        return 'Ajouter la colonne stock à la table produit';
    }

    public function up(Schema $schema): void
    {
        // Ajouter 'stock' de type INT, NOT NULL, DEFAULT 0
        $this->addSql('ALTER TABLE produit ADD COLUMN stock INT NOT NULL DEFAULT 0');
    }

    public function down(Schema $schema): void
    {
        $this->addSql('ALTER TABLE produit DROP COLUMN stock');
    }
}

Méthode index() : Affichage du Panier

La méthode index() récupère le panier stocké en session, enrichit chaque article avec les données produit (nom, prix, stock) et calcule le total.

#[Route('/panier', name: 'app_panier')]
public function index(
    SessionInterface $session,
    ProduitRepository $produitRepo
): Response {
    $panier = $session->get('panier', []);

    $panierComplet = [];
    $total = 0;

    foreach ($panier as $item) {
        $produit = $produitRepo->find($item['productId']);

        if ($produit) {
            $sousTotal = $produit->getPrix() * $item['quantity'];

            $panierComplet[] = [
                'productId' => $produit->getId(),
                'name'      => $produit->getNom(),
                'price'     => $produit->getPrix(),
                'quantity'  => $item['quantity'],
                'total'     => $sousTotal,
                'stock'     => $produit->getStock()
            ];

            $total += $sousTotal;
        }
    }

    return $this->render('panier/index.html.twig', [
        'panier' => $panierComplet,
        'total'  => $total
    ]);
}

Fonctionnement : Pour chaque article du panier en session, on charge le produit depuis la BDD pour obtenir les données à jour (prix, stock). Le sous-total est calculé par article, et le total général est transmis au template Twig.

Méthode ajouter() : Ajout au Panier avec Vérification du Stock

#[Route('/panier/ajouter', name: 'app_panier_ajouter', methods: ['POST'])]
public function ajouter(
    Request $request,
    SessionInterface $session,
    ProduitRepository $produitRepo
): Response {
    $productId = (int) $request->request->get('product_id');
    $quantite  = (int) $request->request->get('quantite', 1);

    $produit = $produitRepo->find($productId);

    if (!$produit) {
        $this->addFlash('error', 'Produit introuvable !');
        return $this->redirectToRoute('app_panier');
    }

    $panier = $session->get('panier', []);

    // Si le produit est déjà dans le panier
    foreach ($panier as $key => $item) {
        if ($item['productId'] === $productId) {
            $nouvelleQte = $item['quantity'] + $quantite;

            // === VÉRIFICATION DU STOCK ===
            if ($nouvelleQte > $produit->getStock()) {
                $this->addFlash('error',
                    "Stock insuffisant ! Seulement
                    {$produit->getStock()} disponible(s).");
                return $this->redirectToRoute('app_panier');
            }

            $panier[$key]['quantity'] = $nouvelleQte;
            $session->set('panier', $panier);
            return $this->redirectToRoute('app_produit');
        }
    }

    // Nouveau produit — vérifier le stock
    if ($quantite > $produit->getStock()) {
        $this->addFlash('error', "Stock insuffisant !");
        return $this->redirectToRoute('app_produit');
    }

    $panier[] = ['productId' => $productId, 'quantity' => $quantite];
    $session->set('panier', $panier);

    $this->addFlash('success', "{$produit->getNom()} ajouté au panier !");
    return $this->redirectToRoute('app_produit');
}

Sécurité stock : La vérification du stock se fait avant l'ajout au panier. Si le produit est déjà présent, on vérifie que la quantité cumulée ne dépasse pas le stock disponible.

Méthode paiementEffectue() : Validation et Décrément du Stock

#[Route('/panier/paiement-effectue',
    name: 'app_panier_paiement_effectue', methods: ['POST'])]
public function paiementEffectue(
    SessionInterface $session,
    EntityManagerInterface $em,
    ProduitRepository $produitRepo
): Response {
    $panier = $session->get('panier', []);
    $user   = $session->get('user');

    if (empty($panier)) {
        $this->addFlash('error', 'Votre panier est vide !');
        return $this->redirectToRoute('app_panier');
    }

    try {
        foreach ($panier as $item) {
            $produit = $produitRepo->find($item['productId']);
            if (!$produit) continue;

            // === VÉRIFICATION FINALE DU STOCK ===
            if ($item['quantity'] > $produit->getStock()) {
                $this->addFlash('error',
                    "Stock insuffisant pour
                    {$produit->getNom()}");
                return $this->redirectToRoute('app_panier');
            }

            // Création de la commande
            $commande = new Commande();
            $commande->setNomClient(
                $user ? $user['nom'] : 'Client anonyme');
            $commande->setProduit($produit->getNom());
            $commande->setQuantite($item['quantity']);
            $commande->setPrix($produit->getPrix());
            $commande->setImage($produit->getImage());
            $commande->setDateCommande(new \DateTime());

            // === DÉCRÉMENT DU STOCK ===
            $produit->decrementStock($item['quantity']);
            $produit->setUpdatedAt(new \DateTimeImmutable());

            $em->persist($commande);
            $em->persist($produit);
        }

        $em->flush();  // Sauvegarde atomique
        $session->remove('panier');

        $this->addFlash('success',
            'Paiement effectué et commande enregistrée !');
    } catch (\Exception $e) {
        $this->addFlash('error', 'Erreur : ' . $e->getMessage());
    }

  • Création de commande : chaque article génère un enregistrement Commande

    methods: ['POST'])]
public function nouveauProduit(
    Request $request,
    SessionInterface $session,
    EntityManagerInterface $em

    $user = $session->get('user');
    if (!$user || $user['role'] !== 'admin') {
        return $this->redirectToRoute('app_home');
    }

    $produit = new Produit();
    $produit->setNom($request->request->get('nom'));
    $produit->setDescription($request->request->get('description'));
    $produit->setPrix((float) $request->request->get('prix'));
    $produit->setStock((int) $request->request->get('stock', 0));
    $produit->setActif(true);
    $produit->setCreatedAt(new \DateTimeImmutable());
    $produit->setUpdatedAt(new \DateTimeImmutable());

    // Gestion de l'image uploadée
    $imageFile = $request->files->get('image');
    if ($imageFile) {
        $fileName = uniqid() . '.' . $imageFile->guessExtension();
        $imageFile->move('uploads/produits', $fileName);
        $produit->setImage($fileName);
    }

    $em->persist($produit);
    $em->flush();

    $this->addFlash('success', 'Produit créé avec succès !');
    return $this->redirectToRoute('app_admin');
}

Chapitre 11 — Flux de Gestion du Stock

11. Flux Complet de Gestion du Stock

Le système de gestion de stock MossAir repose sur un flux en 4 étapes qui garantit la cohérence des données entre l'affichage, le panier et la base de données.

Diagramme du Flux

1
Vérification du stock
L'utilisateur consulte un produit → hasStock() vérifie si stock > 0
↓
2
Ajout au panier
PanierController::ajouter() → double vérification (produit existe ET stock disponible)
↓
3
Validation et Paiement
paiementEffectue() → création commande + decrementStock() pour chaque article
↓
4
Mise à jour BDD
EntityManager::flush() → stock décrémenté en base → badges admin mis à jour automatiquement

Exemple Concret

Scénario : Le produit « Moss Air 3 » a un stock de 8 unités.

  1. Le client visite la fiche produit → hasStock() retourne true → bouton « Ajouter au panier » visible
  2. Le client ajoute 2 exemplaires → session panier = [produit_id => 2]
  3. Le client valide sa commande → decrementStock(2) exécuté
  4. Stock en BDD passe de 8 → 6 → badge admin reste 6 OK

Chapitre 12 — Sécurité

12. Sécurité de l'Application

La sécurité est un aspect fondamental de MossAir. Cinq axes principaux sont mis en œuvre pour protéger les données et les accès.

🔒

Authentification et Autorisation

Système d'authentification Symfony avec hashage bcrypt des mots de passe. Séparation des rôles ROLE_USER et ROLE_ADMIN via le composant Security. Accès admin protégé par annotation @IsGranted('ROLE_ADMIN').

🛡

Protection CSRF

Tous les formulaires incluent un token CSRF généré automatiquement par Symfony. Les requêtes POST sans token valide sont rejetées, empêchant les attaques Cross-Site Request Forgery.

🗃

Validation des Données

Validation côté serveur via les Assert Constraints de Symfony (NotBlank, Length, Positive). Les données utilisateur sont toujours vérifiées avant insertion en base. L'ORM Doctrine protège contre les injections SQL via les requêtes paramétrées.

📄

Upload Sécurisé

L'upload d'images produit (admin) est sécurisé : vérification du type MIME, renommage avec uniqid() pour éviter les conflits et injections de nom de fichier, stockage dans un répertoire dédié hors de la racine publique sensible.

👁

Accès Admin Secret

L'accès au dashboard admin est doublement protégé : côté serveur par le rôle ROLE_ADMIN, et côté client par un accès secret (Ctrl+A + triple-clic sur le logo) qui révèle le lien admin. Cette double couche ajoute une sécurité par obscurité en complément.

    $user = $this->getUser();
    $user->setPrenom($request->get('prenom'));
    $user->setNom($request->get('nom'));

    // Upload photo de profil
    if ($file = $request->files->get('photo')) {
        $filename = uniqid().'.'.$file->guessExtension();
        $file->move($this->getParameter('uploads_dir'), $filename);
        $user->setPhoto($filename);
    }
    $this->em->flush();
}

22.2 Système Newsletter

Le site intègre un système d'inscription à la newsletter pour fidéliser les clients :

Restez informé(e) !

votre@email.com

PHP — NewsletterController (extrait)
#[Route('/newsletter/subscribe', methods: ['POST'])]
public function subscribe(Request $request): JsonResponse
{
    $email = $request->get('email');

    // Validation email
    if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
        return new JsonResponse(['error' => 'Email invalide'], 400);
    }

    // Vérification doublon
    $existing = $this->repo->findOneBy(['email' => $email]);
    if ($existing) {
        return new JsonResponse(['message' => 'Déjà inscrit']);
    }

    $subscriber = new Newsletter();
    $subscriber->setEmail($email);
    $this->em->persist($subscriber);
    $this->em->flush();

    return new JsonResponse(['message' => 'Inscription réussie !']);
}

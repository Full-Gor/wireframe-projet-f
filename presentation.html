Le Produit : Moss Air

Moss Air est un purificateur d'air révolutionnaire utilisant la mousse vivante stabilisée pour filtrer naturellement l'air intérieur.

Concept & Objectifs

  • Filtration naturelle par mousse vivante
  • Objectif : réduction significative des particules fines et COV
  • Inspiré de solutions de biofiltre végétal existantes
  • Faible consommation énergétique (concept passif)
  • Sans filtre à changer, fonctionnement silencieux
  • Design minimaliste et élégant

Pourquoi Symfony ?

  • Architecture MVC : Séparation claire modèles/vues/contrôleurs
  • Doctrine ORM : Gestion simplifiée de la BDD
  • Sécurité intégrée : CSRF, hachage, contrôle d'accès
  • Twig : Protection XSS automatique
  • Migrations : Versioning de la BDD
  • Communauté active : Documentation riche

  • Produit → Commande : un produit apparaît dans plusieurs commandes (1:N)
  • Stock : ajouté via migration Doctrine (colonne stock sur Produit)

Gestion du Panier & Stock

Flux de gestion du stock

Utilisateur ajoute au panier
POST /panier/ajouter
Vérification stock disponible
IF quantité > stock → Erreur
Panier mis à jour en session
POST /panier/paiement-effectue
decrementStock()
Stock décrémenté + Commande enregistrée

Code : decrementStock() (Entity/Produit.php)

public function decrementStock(int $quantity): static { // Empêcher le stock de devenir négatif $this->stock = max(0, $this->stock - $quantity); return $this; }

Code : Appel dans PanierController

// Lors du paiement effectué foreach ($panier as $item) { $produit = $produitRepo->find($item['id']); $produit->decrementStock($item['quantity']); } $em->flush(); // Transaction atomique

Sécurité

Authentification

  • bcrypt — mots de passe hachés

Protection CSRF

  • Tokens générés automatiquement par Twig

// AuthController.php - Inscription $hashedPassword = $passwordHasher ->hashPassword($user, $data['password']); $user->setPassword($hashedPassword);

Code : Protection CSRF (Twig)

<!-- Token CSRF auto dans les formulaires --> <input type="hidden" name="_csrf_token" value="{{ csrf_token('authenticate') }}">
